# Scene and control map

| Route | Purpose | Object and motion | Direct navigation / fallback |
|---|---|---|---|
| Home `#/` | Explore four interests | Two metallic CSS rings orbit a central sphere; bounded floating movement | Four ordinary links, no mandatory intro; static CSS composition with reduced motion |
| IT `#/category/it` | Browse gadget stories | Original abstract miniature terminal; gentle float | Search and article links, no drag required |
| Apple `#/category/apple` | Browse source-aware Apple coverage | Metallic ring, distinct from Apple trademarks | Ordinary reading list and direct article routes |
| Skin `#/category/skin` | Browse ingredient/self-care notes | Abstract translucent bottle | Same full content with motion stopped |
| Style `#/category/style` | Browse Thai design | Original folded fabric sculpture | No copied garment patterns; text links always work |
| Article `#/article/:id` | Read without distraction | Static category motif | Sources/status and back link; no reading animation |
| Archive `#/archive` | Search, save and browse source files | Static card illustrations | Filters, labeled search, date-bearing titles and Drive source links |
| About `#/about` | Explain editorial and rights status | Typography | Static complete page |

Continuous movement: home sculpture and category hero objects. The header pause button stops CSS animations. OS reduced-motion disables animations and transitions. Scroll remains native and does not move the camera. All actions work by keyboard and touch. Unsupported 3D transforms degrade to static shapes without losing content. No WebGL or model downloads are required. Saved stories stay in browser local storage; failure produces an honest temporary-storage message.
